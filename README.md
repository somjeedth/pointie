# Pointie — Customer Web App

เว็บแอพฝั่งลูกค้าของ **Pointie** (แตะ · สะสม · เลเวลอัป) สร้างจากดีไซน์ `Pointie — Customer App` ทั้ง 26 หน้าจอ
เป็น HTML/CSS/JS ล้วน (ES modules, ไม่ต้อง build) ติดตั้งเป็นแอพบนมือถือได้ (PWA) และใช้งานออฟไลน์ได้บางส่วน

## เปิดใช้งาน

```bash
python3 -m http.server 8000
# แล้วเปิด http://localhost:8000/
```

ต้องเปิดผ่านเว็บเซิร์ฟเวอร์ (ไม่ใช่ `file://`) เพราะใช้ ES modules และ service worker

## Deploy บน Vercel

1. vercel.com → **Add New → Project** → เลือก repo `somjeedth/pointie`
2. Framework Preset → **Other** · ไม่ต้องมี Build Command / Root Directory
3. **Deploy** → แอพจะอยู่ที่หน้าแรกของโดเมน (เช่น `pointie-xxx.vercel.app`)

header ความปลอดภัย (CSP, เปิดกล้อง/ตำแหน่งให้แอพ) อยู่ใน `vercel.json`

## ลิงก์สำหรับสแตนด์ NFC / QR ของร้าน

เขียน URL นี้ลงแท็ก NFC หรือทำเป็น QR: `https://<โดเมน Pointie>/#/tap/<shopId>`
เช่น `#/tap/baan` · `jae` · `plant` · `climb` · `noodle` · `roast` · `book` · `clay`

- แตะแล้วยังไม่ล็อกอิน → หน้าเข้าสู่ระบบ แล้วกลับมารับแสตมป์อัตโนมัติ
- Android Chrome อ่าน NFC ในแอพได้ (Web NFC) · เบราว์เซอร์ที่มี `BarcodeDetector` สแกน QR ด้วยกล้องในแอพได้
- เบราว์เซอร์อื่นมีปุ่มเลือกร้านเพื่อจำลองการแตะ

## กติกาที่ทำไว้
- แสตมป์ได้ร้านละ 1 ดวงต่อวัน · บ้านกาแฟริมคลองได้ x2 ทุกวันพุธ · บัตรครบต้องแลกก่อนเริ่มใบใหม่
- XP: แสตมป์ +20 · รีวิว +30 · ตอบความชอบ +30 · สมัครใหม่ +50 · ภารกิจรายสัปดาห์ +30 ถึง +100
- รีวิวได้เฉพาะร้านที่เคยรับแสตมป์ (ป้าย "ไปจริง")
- กดรับแสตมป์ตอนออฟไลน์ ระบบจะเก็บการแตะไว้ 10 นาที แล้วบันทึกให้เมื่อกลับมาออนไลน์
- เลเวลอัปปลดล็อกช่องปักหมุด Badge และกรอบนามบัตร (Lv.8 = ลายส้มทอง) · สลับธีมมืด/สว่างได้ที่ ตั้งค่า

## เว็บร้านค้า (`/merchant/`)

เปิดที่ `http://localhost:8000/merchant/` (หรือ `<โดเมน>/merchant/` บน Vercel)
บัญชีตัวอย่าง: `owner@baan.cafe` / `demo1234` (ร้านบ้านกาแฟริมคลอง) หรือกด "สมัครร้านใหม่"

| เมนู | ทำอะไรได้ |
|---|---|
| Dashboard | แตะวันนี้/7/30 วัน, ลูกค้า, ลูกค้าใหม่, อัตรากลับมาซ้ำ, การแลก, คะแนนรีวิว, กราฟรายวัน, ช่วงเวลาที่คนมา, ลูกค้าที่บัตรใกล้ครบ, กิจกรรมล่าสุด |
| ยืนยันแลกรางวัล | ใส่รหัส 4 หลักจากจอลูกค้า → ยืนยัน/ยกเลิก + ประวัติการแลก |
| ข้อมูลร้าน & แมพ | ชื่อ หมวด ย่าน ที่อยู่ เบอร์ เวลาเปิด-ปิด คำแนะนำร้าน + ลากหมุดบนแมพ |
| ออกแบบบัตรสะสม | ข้อความบนบัตร จำนวนดวง รางวัล สี ลายพื้น ไอคอน พร้อมพรีวิวแบบที่ลูกค้าเห็น |
| โปรและกิจกรรม | ข้อความโปร ระยะเวลา แสตมป์ x2 ตามวัน และกิจกรรมพิเศษ (ขึ้นป้าย "โปร" บนแมพ) |
| จุดแตะ NFC / QR | สร้างสแตนด์ ลิงก์ + QR, พิมพ์ป้าย, เขียนแท็ก NFC (Android Chrome), ปิด/เปลี่ยนรหัสเมื่อแท็กหาย |
| รีวิว | อ่านและตอบกลับ (คำตอบแสดงใต้รีวิวในหน้าร้านของลูกค้า) |
| ลูกค้า | รายชื่อ (ชื่อเล่นเท่านั้น) จำนวนครั้ง บัตรปัจจุบัน กรอง: ใกล้ครบ / ครบรอแลก / ใหม่ / หายไปนาน |
| ตั้งค่า | ซ่อนร้านจากแอพชั่วคราว ธีม ออกจากระบบ |

**ข้อมูล:** ทั้งแอพลูกค้าและเว็บร้านค้าใช้หลังบ้าน **Supabase** ร่วมกัน (ตั้งค่าใน `js/config.js`)
ร้านแก้ข้อมูล → ลูกค้าเห็นทุกเครื่อง, ลูกค้าแตะ/แลก/รีวิว → ขึ้นใน Dashboard ร้าน
วิธีติดตั้งฐานข้อมูล: ดู [`supabase/README.md`](supabase/README.md)
ถ้ายังต่อ Supabase ไม่ได้ ทั้งสองเว็บจะสลับไปใช้โหมดเดโมใน `localStorage` เอง (หรือบังคับด้วย `?local=1`)

## หน้า landing สำหรับร้านค้า (`/business/`)
หน้าแนะนำ Pointie ให้เจ้าของร้าน → ปุ่ม **สมัครใช้งาน** เปิดฟอร์มเก็บ ชื่อ นามสกุล เบอร์โทร ชื่อร้าน ประเภทร้าน ลงตาราง `leads` ให้ทีมงานโทรกลับ (ดูใน Supabase → Table Editor)
- **ตัวเลขสดจากระบบ** (ฟังก์ชัน `public_stats`): ร้าน ลูกค้า แสตมป์ที่แจก รางวัลที่แลก รีวิว — นับเฉพาะข้อมูลจริง และโชว์เฉพาะตัวที่ถึงเกณฑ์ขั้นต่ำ
- **ตัวเลขที่ร้านวัดได้** พร้อมภาพ Dashboard (ระบุว่าเป็นข้อมูลจำลอง)
- **เครื่องคิดเลขประมาณการ** รายได้เพิ่ม/ต้นทุนรางวัลจากตัวเลขของร้านเอง
- ภาพหน้าจอใน `business/img/` ถ่ายจากแอพจริง (โหมดเดโม)

```
./
├── index.html, manifest.webmanifest, sw.js, vercel.json
├── css/app.css            ธีม (มืด/สว่าง) และคอมโพเนนต์
├── img/                   มาสคอต Pointie และไอคอนแอพ
└── js/
    ├── app.js             router (hash) + event delegation
    ├── store.js           state, กติกาแสตมป์/XP/ภารกิจ/Badge (Supabase หรือ localStorage)
    ├── remote.js, config.js   เชื่อม Supabase (เรียกผ่านฟังก์ชัน rpc เท่านั้น)
    ├── data.js            ร้าน, Badge, เลเวล, ตัวเลือกความชอบ
    ├── ui.js, icons.js    คอมโพเนนต์และไอคอน SVG
    └── screens-*.js       หน้าจอ (onboard / main / flow)
```

## โดเมน (getpointie.com)
| โดเมน | เว็บ | ไฟล์ |
|---|---|---|
| `getpointie.com` และ `www.getpointie.com` | หน้า landing สำหรับร้านค้า | `business/` |
| `app.getpointie.com` | แอพลูกค้า (ลิงก์ NFC/QR ของสแตนด์ชี้มาที่นี่) | root |
| `store.getpointie.com` | เว็บร้านค้า | `merchant/` |

ทั้งหมดเป็นโปรเจกต์ Vercel เดียว: `vercel.json` (`routes`) เลือกหน้าแรกตามชื่อโดเมน และลิงก์ข้ามเว็บสร้างจาก `js/sites.js`
โค้ดไม่ redirect ระหว่าง `www` กับโดเมนหลัก — ถ้าจะ redirect ให้ตั้งใน Vercel → Domains ทางเดียว (ไม่งั้นจะวนไม่จบ)
บนโดเมนอื่น (เช่น `*.vercel.app`, localhost) ทั้ง 3 เว็บยังเปิดเป็นโฟลเดอร์ได้เหมือนเดิม (`/`, `/merchant/`, `/business/`)
