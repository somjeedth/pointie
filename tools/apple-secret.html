สร้าง Secret Key สำหรับ Sign in with Apple

หน้านี้คำนวณในเบราว์เซอร์ของคุณเท่านั้น ไม่ส่งข้อมูลหรือไฟล์ .p8 ไปที่ไหน (ปิดเน็ตแล้วใช้ก็ได้)

ไฟล์ .p8 ไฟล์ AuthKey_XXXXXXXXXX.p8 ที่ดาวน์โหลดตอนสร้าง key
แตะเพื่อเลือกไฟล์ .p8 หรือลากไฟล์มาวางตรงนี้

สร้างแล้ว ✓ ใช้ได้ถึง

  1. ไปที่ Supabase → Authentication → Sign In / Providers → Apple
  2. เปิด Enable · Client IDs:
  3. วางค่านี้ในช่อง Secret Key (for OAuth) → Save
  4. ตั้งเตือนในปฏิทินให้สร้างใหม่ก่อนวันหมดอายุ (ใช้ไฟล์ .p8 เดิมได้)
